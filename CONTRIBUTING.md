# Contributing

This repository is `gridshell`, the MIT-licensed Python package that's the self-hosted server and client library backing the GridShell Google Sheets add-on. The add-on itself is closed source, distributed only through the Google Workspace Marketplace, and isn't part of this repository - see [License](https://gridshell.app/legal/license/) for why the split, and for both components' terms.

## Bug reports and feature requests

Welcome for either component, via GitHub issues. Please include:

- Whether it's the App, the Library, or both.
- Your OS and, if relevant, Python version (`python3 --version`).
- The exact error message, if any.

## Code contributions

**Not accepted yet.** GridShell is early (currently a beta release) and solo-maintained, with a security-sensitive surface (it spawns a real interactive shell) - reviewing outside code changes carefully takes time this project doesn't have the process for yet. This will be revisited once there's a stable, non-beta release. Feel free to open an issue to discuss an idea in the meantime; it just won't be merged as a PR yet.

## Reporting a security vulnerability

Don't open a public issue for this - see [SECURITY.md](SECURITY.md) instead.

## Code of conduct

None yet. This repository's only open interaction surface right now is bug-report issues into a solo maintainer, with no community activity for a code of conduct to actually govern - it'll be added once code contributions reopen (see above), most likely adopting the [Contributor Covenant](https://www.contributor-covenant.org/).
